CyberSafe Vault

CyberSafe Vault is a Java-based cybersecurity application developed by Saanvi Nayak. The application allows users to securely store, search, delete, save, and load password entries while promoting good cybersecurity practices.

Features
Store passwords for multiple websites and accounts
Encrypt passwords before storage
Decrypt passwords when viewing entries
Check password strength (Weak, Medium, Strong)
Detect duplicate passwords
Search saved passwords
Delete saved passwords
Save and load vault data from a text file
Display a cybersecurity threat tree
Unit testing with JUnit

Technologies Used
Java
Object-Oriented Programming (OOP)
ArrayList Collections
File I/O
Recursion
JUnit Testing

Security Features
Passwords are encrypted before being stored.
Password strength validation encourages stronger passwords.
Duplicate password detection helps identify password reuse.
Threat tree visualization introduces common cybersecurity risks.

How to Run
Install Java JDK.
Open the project in VS Code or IntelliJ IDEA.
Add the JUnit libraries from the lib folder.
Compile all Java files.
Run Main.java.
Use the menu-driven interface to manage passwords.
